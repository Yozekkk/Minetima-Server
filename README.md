## Текущее содержимое

На данный момент в репозитории есть только этот `README.md`. Конфигурации плагинов, файлы русификации и настройки сервера, перечисленные в прежнем описании, пока не опубликованы. Здесь также нет серверного ядра, скриптов запуска, тестов, GitHub Actions и `LICENSE`.

## Использование

Скачать или запустить сервер из этого репозитория сейчас нельзя: для установки не хватает файлов и проверенной инструкции. Когда содержимое будет опубликовано, команды запуска и требования к версии сервера следует документировать по фактическим файлам, а не по названию проекта.
